PhoneCash SMS API Documentation

GrizzlySMS مۇلازىمەتلىرىنى ئۆزிڭىزنىڭ تور بېتى ياكى ئەپلىرىگە ئۇلاش ئۈچۈن مەخسۇس RESTful API قوللانمىسى

ئاساسىي ئۇچۇرلار

بارلىق تەلەپلەر (request) تۆۋەندىكى ئاساسىي URL ئارقىلىق بىر تەرەپ قىلىنىدۇ:

https://app.phonecash.sy/api/api.php
مۇھىم ئىزاھات: بارلىق تەلەپلەردە خېرىدارلارنىڭ api_key سى چوقۇم پارامېتىر سۈپىتىدە بىللە ئەۋەتىلىشى كېرەك.

0. بالانس سۈرۈشتۈرۈش (getBalance)

خېرىدارنىڭ نۆۋەتتىكى بالانسىنى (USD) كۆرسىتىدۇ.

GET / POST https://app.phonecash.sy/api/api.php?action=getBalance&api_key=Sizning_ApiKey

جاۋاب قۇرۇلمىسى (Response):

{
    "success": true,
    "message": "success",
    "data": {
        "balance": 25.50
    }
}

1. دۆلەت تىزىملىكىنى ئېلىش

قوللىنىشقا بولىدىغان دۆلەتلەر ۋە ئۇلارنىڭ كودلىرىنى قايتۇرىدۇ.

GET / POST https://app.phonecash.sy/api/api.php?action=getCountries&api_key=Sizning_ApiKey

جاۋاب قۇرۇلمىسى (Response):

{
    "success": true,
    "message": "success",
    "data": [
        {
            "id": "0",
            "name": "Russia",
            "code": "ru",
            "flag": "🇷🇺"
        }
    ]
}

2. مۇلازىمەت ۋە باھا تىزىملىكى

مەخسۇس دۆلەت بويىچە مۇلازىمەتلەرنى ۋە چىقىرىۋېلىنغان باھالارنى قايتۇرىدۇ.

GET / POST https://app.phonecash.sy/api/api.php?action=getServices&country=0&api_key=Sizning_ApiKey

پارامېتىرلار:

پارامېتىر تىپى چۈشەندۈرۈش
country Integer دۆلەت ID كودى (مەسلەن: 0 روسىيە ئۈچۈن)

جاۋاب قۇرۇلمىسى (Response):

{
    "success": true,
    "message": "success",
    "data": [
        {
            "service_code": "tg",
            "name": "TG",
            "price": 15.50,
            "original_price": 18.00,
            "number_discount_percent": 15.0,
            "count": 450
        }
    ]
}

3. نومۇر سېتىۋېلىش

بەلگىلەنگەن مۇلازىمەت ۋە دۆلەت بويىچە تېلېفون نومۇرى سېتىۋالىدۇ.

GET / POST https://app.phonecash.sy/api/api.php?action=buyNumber&service=tg&country=0&api_key=Sizning_ApiKey

پارامېتىرلار:

پارامېتىر تىپى چۈشەندۈرۈش
service String مۇلازىمەت كودى (مەسلەن: tg - Telegram)
country Integer دۆلەت ID كودى

جاۋاب قۇرۇلمىسى (Response):

{
    "success": true,
    "message": "success",
    "data": {
        "id": "680730548",
        "number": "+84355309920",
        "price": 15.50
    }
}

4. نومۇر ھالىتىنى تەكشۈرۈش ۋە كود ئوقۇش (getStatus)

نومۇرغا SMS كەلگەن-كەلمىگەنلىكىنى تەكشۈرىدۇ. كود كەلگەن ھامان ئابونتنىڭ بالانسىدىن پۇل تۇتۇلىدۇ.

GET / POST https://app.phonecash.sy/api/api.php?action=checkStatus&id=680730548&service=tg&country=0&api_key=Sizning_ApiKey

پارامېتىرلار:

پارامېتىر تىپى چۈشەندۈرۈش
id String نومۇر سېتىۋالغاندا كەلگەن Activation ID
service String مۇلازىمەت كودى (پۇل ھېسابلاش ئۈچۈن كېرەك)
country Integer دۆلەت ID كودى

جاۋاب قۇرۇلمىسى (Response):

{
    "success": true,
    "message": "success",
    "data": {
        "status_text": "Code Received",
        "code": "123456",
        "raw_response": "STATUS_OK:123456"
    }
}
