# AUTO CASH - Digital Services & Game Top-Up Platform

AUTO CASH (ئەپلەرگە، ئويۇنلارغا پۇل قاچىلاش ۋە رەقەملىك مۇلازىمەتلەر سۇپىسى) is a modern, responsive web application for instant game top-ups, mobile apps recharge, AI subscriptions, and virtual cards with multi-language support (Uyghur, Arabic, English).

## Features
- **3 Languages Support (i18n)**: Pure Uyghur (RTL), Arabic (RTL), and English (LTR).
- **Instant Sham Cash & USDT Payments**: Direct verification & automated workflow.
- **Service Categories**: Games, Apps, AI Tools, Virtual Numbers, Gift Cards & VCC, Ready Accounts, Crypto, Social Media, Local Wallets.
- **VIP Membership System**: Tier progression (Bronze, Silver, Gold, Platinum, Diamond) with automated discounts.
- **Order Management & Tracking**: Real-time status filters (Completed, Processing, Cancelled).
- **Modern UI/UX**: Built with Next.js 14, Tailwind CSS, Lucide icons, UKIJ & Alkatip typography.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm start
```
