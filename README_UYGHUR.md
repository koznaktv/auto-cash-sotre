# AUTO CASH - ئىشلىتىش ۋە ئېلان قىلىش قوللانمىسى

بۇ تۈر Next.js 14، TypeScript ۋە Tailwind CSS ئاساسىدا ئىشلەنگەن تولۇق رەقەملىك ماللار، ئويۇن ۋە ئەپلەرگە پۇل قاچىلاش سۇپىسى.

---

## 🚀 1. سىستېمىنى قوزغىتىش تەرتىپى

كومپيۇتېرىڭىزدا Node.js (v18 ياكى ئۇنىڭدىن يۇقىرى) بولۇشى كېرەك.

### 1-قەدەم: كېرەكلىك بوغچىلارنى قاچىلاش
تۈر قىسقۇچىغا كىرىپ، بۇيرۇق كۆزنىكىدە (Terminal / PowerShell) تۆۋەندىكى بۇيرۇقنى بېرىڭ:
```bash
npm install
```

### 2-قەدەم: ئىشلەپچىقىرىش قۇرۇلمىسىنى يىغىش (Build)
```bash
npm run build
```

### 3-قەدەم: سىستېمىنى يۈرگۈزۈش (Production Start)
```bash
npm run start
```
ئەگەر كود ئۆزگەرتىش ياكى ئاچقۇچى ھالىتىدە يۈرگۈزمەكچى بولسىڭىز:
```bash
npm run dev
```

## 📁 3. مۇھىم قىسقۇچ ۋە ھۆججەتلەر قۇرۇلمىسى

- `data/autocash_db.json`: بارلىق ئەزالار، تالونلار، زاكازلار ۋە سىستېما تەڭشەكلىرى ئاپتوماتىك ساقلىنىدىغان مەڭگۈلۈك سانلىق-مەلۇمات بازىسى.
- `src/lib/db.ts`: سانلىق-مەلۇماتلارنى باشقۇرۇش، مەخپىي شىفىرلاشتۇرۇش (PBKDF2/SHA-512) ۋە ھەميان قالدۇقىنى بىر تەرەپ قىلىش مەركىزى.
- `src/lib/adminAuth.ts`: باشقۇرغۇچى كىرىش قالقىنى ۋە بىخەتەرلىك تەكشۈرۈش لوگىكىسى.
- `src/app/api/`: رەسمىي ئەزا تىزىملىتىش، كىرىش، زاكاز ۋە پۇل كىرگۈزۈش ئارقا سۇپا API ئېغىزلىرى.
- `next.config.mjs`: تاشقى سۈرەت ساھە ناملىرى ۋە بىخەتەرلىك تەڭشەكلىرى.
